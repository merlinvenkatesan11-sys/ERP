# 🎓 College ERP System

An interactive, responsive Single-Page College Enterprise Resource Planning (ERP) web application built using **React** with custom modern styling (Dark Sidebar + Clean Dashboard layout).

## 🚀 Live Demo & Access

Open `index.html` or `college-erp.html` in any modern web browser. No complex installation or build step needed.

## ✨ Features

### 1. 🛡️ Admin Portal
- **Dashboard Stats**: Active student count, faculty count, total courses, attendance rates.
- **Student Management**: Full student directory table with Roll No, Branch, CGPA, and Status badges.
- **Staff Directory**: Faculty listing with Department, Designation, Course counts, and Status indicators.
- **Action Cards**: System reports, configurations, notifications, and analytics.

### 2. 👨‍🏫 Faculty / Staff Portal
- **Dashboard Overview**: Enrolled students, teaching courses, attendance rates, pending assessments.
- **Course Management**: Detailed course table with enrolled counts, syllabus progress bars, and status.
- **Attendance Records**: Date-wise attendance logs with Present/Absent/Total breakdown and progress visualizers.
- **Action Hub**: Attendance marking, assignment grading, resource uploads, and student performance tracking.

### 3. 🎓 Student Portal
- **Dashboard Summary**: Enrolled courses, average marks, attendance metrics, and GPA counter.
- **Course Performance**: Course-wise visual progress bars and letter grades (A, B, C, D).
- **Course Directory**: Enrolled courses with instructors, credit values, and grade cards.
- **Fee Statement**: Semester-by-semester breakdown, tuition fees, paid/pending status, and Pay Now action.
